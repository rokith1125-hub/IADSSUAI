# 📖 Project Overview

The Intelligent Agriculture Decision Support System is an AI-powered web application designed to support farmers throughout the agricultural lifecycle. The platform integrates multiple Artificial Intelligence modules into a single system, enabling intelligent decision-making based on soil conditions, crop suitability, plant health, weather forecasts, and market trends.

The system uses Convolutional Neural Networks (CNNs) for soil and plant disease classification while Machine Learning models and intelligent recommendation logic provide personalized farming guidance. The goal is to simplify agricultural decision-making, improve productivity, and promote sustainable farming practices.
